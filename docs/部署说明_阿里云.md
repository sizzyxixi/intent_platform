# 部署说明：阿里云 ECS（香港）

## 访问
- 地址：http://intent.47.86.15.93.sslip.io/ （sslip.io 是公共通配 DNS，域名直接解析到 47.86.15.93，无需备案和购买域名）
- 管理员：沿用库里已有账号（admin）
- 健康检查：http://intent.47.86.15.93.sslip.io/healthz
- 说明：服务器 80/443 由已有的 agentscope（Moonclaw）站点的 Caddy 占用，`http://47.86.15.93/` 仍是那个站点。本平台按域名分流，不影响原站点。以后有正式域名时，把域名解析到 47.86.15.93，再用 `HOST_NAME=新域名` 重新部署即可（去掉 Caddyfile 站点前缀 `http://` 可让 Caddy 自动申请 HTTPS 证书）。

## 架构
| 组件 | 说明 |
|---|---|
| `intent-platform-app` 容器 | 镜像 `intent-platform-app`（deploy/aliyun/Dockerfile，python:3.12-slim）。FastAPI 同时提供 `/api`、`/mcp`、前端页面；内置 xclaw-cli（未登录）。重启策略 unless-stopped |
| 数据库 | 已有容器 `moonclaw-db-postgres-1`（postgres:17），库 `intent_platform`，账号 `intent_platform_app`。应用通过 docker 网络 `moonclaw-db_default` 以主机名 `postgres` 连接，数据库端口不对外开放 |
| 反向代理 | 已有容器 `agentscope-ecs-proxy-1`（Caddy 2.11），配置文件 `/opt/moonclaw/config/Caddyfile`；追加了 `http://intent.47.86.15.93.sslip.io` 站点，转发到 `intent-platform:8000`（应用容器同时接入 `agentscope-ecs_default` 网络）。修改前的备份为 `Caddyfile.bak.<时间>` |
| 本机调试端口 | `127.0.0.1:8091`（仅服务器本机） |

## 服务器目录
- `/opt/intent-platform/config/database.env`：数据库连接串（root 600，不入库）
- `/opt/intent-platform/config/app.env`：运行配置，部署脚本由 database.env 派生（root 600）
- `/opt/intent-platform/config/secret_key`：会话签名密钥，首次部署自动生成，之后保持不变
- `/opt/intent-platform/src`：当前部署的代码（`src.prev` 为上一版）

## 重新部署
在能 `ssh root@47.86.15.93` 的机器上，仓库根目录执行：
```
bash deploy/aliyun/aliyun_deploy.sh
```
脚本会：构建前端 → 打包当前 HEAD → 上传 → 服务器构建镜像 → 数据库版本落后时执行 `alembic upgrade head`（不导入种子数据、不清库）→ 重建容器 → 首次时追加 Caddy 站点并热加载。

## 常用运维
```
docker logs -f intent-platform-app          # 查看日志
docker restart intent-platform-app          # 重启
docker exec -it intent-platform-app xclaw-cli auth login   # 西之月 CLI 登录（测试调用 CLI 工具需要）
```
xclaw-cli 登录状态保存在容器内，重新部署后需要重新登录；也可以在 app.env 里加 `XCLAW_UMC_TOKEN` 后重启。

## 回滚
```
docker images intent-platform-app             # 每次部署按提交号打 tag
docker rm -f intent-platform-app && docker run -d --name intent-platform-app --restart unless-stopped \
  --network moonclaw-db_default --env-file /opt/intent-platform/config/app.env -p 127.0.0.1:8091:8000 intent-platform-app:<提交号>
docker network connect --alias intent-platform agentscope-ecs_default intent-platform-app
```
