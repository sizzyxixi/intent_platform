## 使用方三句话

1. API Key 只从环境变量 `INTENT_PLATFORM_API_KEY` 或文件 `~/.intent-platform/config.json` 读取；找不到就停下来向人要，不要到其他目录搜索。
2. 先 `GET /api/v1/spaces` 自检，再拉 `GET /api/v1/runtime-config`；识别和多轮状态在你这边做，平台没有识别接口，也不保存会话。
3. 按意图的槽位和绑定工具调用；业务入参以工具定义为准，从会话上下文供给。写操作先确认。平台不代为调用业务工具，也没有通用的输出字段映射。

完整步骤和错误处理见《使用方接入指南》。设计是否覆盖「配置环境后按意图走完一次对话」，见《设计评估_使用方链路》。

## 运营方三句话

1. 配置以控制台登录会话（`/api/admin`）为主。左侧是「意图管理」「知识库」「工具中心」，管理员左下角有「用户与审计」。
2. API Key 只能把意图写成草稿、维护槽位、导入知识和改切片；**不能**启用意图、绑工具或知识、注册工具、新建知识库或管理 Key。
3. 新空间按《运营方配置手册》第 1 节清单走完，再把只读 Key 和《使用方接入指南》交给使用方。
